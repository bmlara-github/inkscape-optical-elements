# Editable examples

Install the extension first. Open an example SVG in Inkscape, select its optical system, and choose **Extensions → Optical Elements → Build System…**. Edit, choose **Apply to Inkscape**, then save a copy under a new name.

- **simple_mirror_system.svg** contains a laser, a concave folding mirror M1, and a plane end mirror M2. Move M2 in the builder to see both mirror orientations follow the connections. M2 has one attached direction and is treated as a normal-incidence end mirror; the return path overlaps the incoming line and is not drawn separately. The worked example is on page 2 of the PDF guide.
- **mach_zehnder.svg** contains an editable Mach-Zehnder layout. Each component and connection can be changed. It illustrates topology, not a balanced or optimized physical interferometer.

The drawings are schematic, not to physical scale. Keep the SVG metadata and generated group intact to reopen them. These original examples use the repository's MIT license.
